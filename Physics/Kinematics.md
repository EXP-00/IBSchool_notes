# Kinematics
### Review
frame of reference is a still frame in time

reference point is the point where motion is relative to

## The Five Kinematic Equations

For constant acceleration motion with variables:
- $u$ = initial velocity
- $v$ = final velocity
- $a$ = acceleration
- $t$ = time
- $s$ = displacement

### Equations
$v = u + at$

$s = ut + \frac{1}{2}at^2$

$v^2 = u^2 + 2as$

$s = vt - \frac{1}{2}at^2$

$s = \frac{u + v}{2}t$
